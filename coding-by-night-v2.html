Begrebsdefinition

Git
Et distribueret versionsstyringssystem til at håndtere samarbejde og historik i en kodebase.
GitHub
En (proprietær) platform til at hoste kodebaser gennem brug af git. Alternativt findes også GitLab, som findes i en AU-hosted udgave (gitlab.au.dk). Endnu tilbyder AU dog ikke Pages, men det kommer vist snart.
GitHub Pages
Gratis og simpel webhostingtjeneste gennem GitHub, som tager udgangspunkt i en kodebase på GitHub (også kaldet et repository))
